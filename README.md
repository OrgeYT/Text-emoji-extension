# Text Emoji Extension

A simple browser extension that lets you insert cute text emojis (kaomoji / text faces) via the right-click context menu.

## Features

- Right-click inside any text field / textarea / contenteditable → **Text emoji**
- Works even **without selecting text**
- Dark-themed floating menu
- Searchable emoji list
- Organized into categories:
  - Happy / Cheerful
  - Smug / Mischievous
  - Sad / Crying
  - Extremely Sad
  - Neutral / Blank
  - Unimpressed / Judging
  - Angry / Frustrated
  - Surprised
  - Shocked / Horrified
  - Sleepy / Yawning
  - Confused / Unsure
  - Worried
  - Winking
  - Love / Hearts
  - Funny / Silly
- Works in regular text fields, textareas, and most contenteditable areas
- Escape key or click outside to close

## Installation (Chrome / Edge / Brave / Opera)

1. Open `chrome://extensions` (or `edge://extensions`, etc.)
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the `text-emoji-extension` folder
5. Done! The extension icon should appear in your toolbar.

## Usage

1. Click inside any text field, textarea, or contenteditable area
2. Right-click → choose **Text emoji**
3. Click the emoji you want — it will be inserted at the cursor (or replace selection if you had one)
4. Use the search bar to quickly find what you need

## Notes

- The context menu appears when you right-click in editable fields (no need to select text).
- On some highly restricted pages (e.g. chrome:// pages, certain extension pages) the menu may not work.
- After updating the extension, click the refresh/reload button on the extension card.
- You can freely edit `content.js` to add, remove, or re-group emojis.
